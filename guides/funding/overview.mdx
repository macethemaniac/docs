Lotus needs venue-ready balances to execute trades quickly.

Funding lets you hold usable capacity for the venues Lotus can route through. The goal is simple for the user: fund once, then let Lotus check which venues are ready before execution.

![Funding readiness flow](/images/learn/funding-readiness-flow.svg)

## What funding does

Funding supports:

- Deposits into Lotus-managed funding wallets.
- Venue-specific activation where required.
- Venue-ready balance checks.
- Withdrawal of available funds.
- Execution readiness for buys and sells.

Funding is not the same as route approval. A venue can have cash available and still be blocked if the market, quote, signer, or settlement path is not safe.

## What users see

The portfolio page should show:

- Funding wallet balances.
- Venue cash balances.
- Which venues are ready to trade.
- Which venues need activation.
- Pending deposits or withdrawals.

Users should not need to know every venue-specific wallet detail.

## What Lotus checks before execution

Before a buy, Lotus checks whether the selected route has enough venue-ready buying power.

Before a sell, Lotus checks whether the user has sellable position on the route venue or venues.

If a venue is not ready, Lotus should return a clear setup action instead of submitting an unsafe order.

## Common mistakes

- Do not treat wallet cash as venue-ready cash.
- Do not assume activation is permanent until the venue confirms readiness.
- Do not use display balances to authorize execution.
- Do not submit a route while funding readiness is blocked.

<Note>
  Funding readiness is an execution gate. It is separate from portfolio display.
</Note>
