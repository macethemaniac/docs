---
title: "Event Types"
---

| Event | Description |
| --- | --- |
| `rfq.created` | An RFQ was created. |
| `rfq.expired` | An RFQ expired unaccepted. |
| `rfq.accepted` | An RFQ quote was accepted. |
| `execution.started` | Execution started on a route. |
| `execution.completed` | Execution verified and complete. |
| `execution.failed` | Execution failed closed. |
| `execution.fallback` | Execution fell back to an alternative route. |
| `funding.completed` | Funding intent credited. |
| `withdrawal.completed` | Withdrawal settled. |
