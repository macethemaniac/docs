---
title: "Venue positions"
description: "How Lotus tracks position state at each venue."
---

Venue positions are the per-venue records that sit under a unified position.

They are important because each venue can use different market IDs, outcome IDs, token IDs, settlement timing, and balance conventions.

## What Lotus tracks

For each venue position, Lotus tracks:

- Venue.
- Venue market ID.
- Venue outcome ID or token ID.
- Side.
- Share size.
- Average entry.
- Sellable amount.
- Last verified status.
- Settlement state.

## Why venue state matters

A user may have one canonical exposure, but execution still happens on venues.

For buys, Lotus needs venue-ready cash.

For sells, Lotus needs verified venue position data and executable outcome identifiers.

## Reconciliation

Venue position data should be reconciled after fills and refreshed when settlement state changes.

If a venue position cannot be verified, Lotus should not use it as sell authority.
